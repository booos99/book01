# مهامي — إدارة المهام اليومية

تطبيق ويب للجوال (PWA) لتسجيل المهام والأهداف والخطط مع نسب الإنجاز والتذكيرات والإشعارات.

**الرابط:** https://booos99.github.io/book01/

## المزايا

- مهام يومية مع التاريخ والوقت والأولوية (عادية / عاجلة)
- مهام متعددة الخطوات مع نسبة إنجاز مئوية
- أهداف مرتبطة بالمهام
- خطط بمراحل قابلة للتحديد
- تذكيرات مرة واحدة أو يومية بين تاريخين
- تعديل وحذف لكل العناصر
- تصدير / استيراد البيانات
- نمط فاتح وداكن
- إشعارات النظام عبر Service Worker

## التشغيل المحلي

```bash
python3 -m http.server 8080
```

ثم افتح: `http://localhost:8080`

## التثبيت على الجوال

1. افتح الرابط في المتصفح
2. أضف إلى الشاشة الرئيسية
3. من تبويب التذكيرات فعّل الإشعارات

## التخزين

البيانات تُحفظ محلياً في المتصفح (`localStorage`) مع نسخة احتياطية، ولا تُرسل إلى أي خادم.
